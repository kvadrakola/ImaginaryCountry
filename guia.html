¿Qué es Bootstrap y cómo lo usamos?

INTRO

Bootstrap es un framework de CSS y JavaScript que nos da componentes listos para usar: menús, botones, formularios, cuadrículas, etc. Solo añadiendo clases en el HTML, sin escribir casi CSS nosotros mismos.

En este proyecto usamos una versión personalizada (no el CDN estándar).

📁 Archivos incluidos

Archivo¿Qué hace?
css/custom-bootstrap.cssEs el CSS de Bootstrap compilado con nuestros colores y estilos personalizados (ver Sección 9).
js/bootstrap.fixed.jsEs el JavaScript de Bootstrap (menú offcanvas, collapse, etc.). Lo llamamos «fixed» porque tiene una corrección para un error con el offcanvas.
scss/styles.scssEl archivo Sass donde definimos colores de la marca y personalizamos variables antes de compilar.
HTML → index.html
 href="css/custom-bootstrap.css" rel="stylesheet">

 src="js/bootstrap.fixed.js">
💡 Dato importante: Bootstrap necesita ambos: el CSS (estilos) y el JS (comportamiento interactivo). Sin el JS, el menú hamburguesa, el offcanvas y el collapse no funcionarían.
🔍 Para tus compañeros: Si quieres usar Bootstrap en otro proyecto, puedes descargarlo o usar un CDN. En nuestro proyecto lo compilamos a medida para tener solo lo necesario.

Sistema de Cuadrícula (Grid)

LAYOUT

El grid de Bootstrap divide la página en 12 columnas. Usando combinaciones de container → row → col-* maquetamos el contenido.

Veamos cómo se usa en nuestro index.html (líneas 48–62):

index.html (hero)
 class="container col-xxl-8 px-4 py-5 mt">
   class="row flex-lg-row-reverse align-items-center g-5 py-5">
    
     class="col-10 col-sm-8 col-lg-6">
       src="..." class="d-block mx-lg-auto img-fluid">
class="col-lg-6"> class="display-5 fw-bold lh-1 mb-3">...

🔎 Clase por clase

containerCrea un contenedor centrado con máximo de ancho (responsive).
col-xxl-8En pantallas extra extra grandes (≥1400px), el contenedor ocupa 8 de 12 columnas.
px-4 / py-5Espaciado interno (padding): px = horizontal, py = vertical. Los números van de 0 a 5.
rowCrea una fila que contiene columnas. Contrarresta el padding del contenedor.
flex-lg-row-reverseEn pantallas grandes (lg+), invierte el orden: la imagen pasa a la derecha y el texto a la izquierda.
align-items-centerCentra verticalmente todas las columnas dentro de la fila.
g-5Gutter = espaciado entre columnas. g-5 da el máximo espacio.
col-10 col-sm-8 col-lg-6Columnas responsive: ocupa 10 cols en móvil, 8 en tablet, 6 en escritorio.
mx-lg-autoMargen horizontal automático → centra la imagen en pantallas grandes.
img-fluidHace que la imagen nunca se desborde y se escale con el contenedor. ¡Imprescindible!

📊 Visualización: cómo se reparten las 12 columnas

col-6 · Imagen
col-6 · Texto

Escritorio: 6 + 6 = 12 ✓

col-8 · Imagen
col-4 · Texto

Tablet: 8 + 4 = 12 ✓

🎯 Regla de oro: La suma de las columnas dentro de una fila debe dar 12. col-6 + col-6 = 12. col-4 + col-4 + col-4 = 12.

Barra de Navegación (Navbar)

NAV

La navbar es el menú superior. Se vuelve un menú hamburguesa en móvil y se despliega con offcanvas en lugar del clásico menú desplegable.

index.html líneas 13–46
 class="navbar navbar-expand-lg fixed-top bg-secondary">
   class="container-fluid">
     class="navbar-brand text-primary" href="#">
       src="..." class="d-inline-block align-text-top">
       class="fs-2 fw-bold lh-1">República de Amargia
    
     class="navbar-toggler" data-bs-toggle="offcanvas">
       class="navbar-toggler-icon">

🔎 Clase por clase

navbarActiva los estilos de barra de navegación de Bootstrap.
navbar-expand-lgSe muestra horizontal en escritorio (lg+). En móvil aparece el botón hamburguesa.
fixed-topFija la barra arriba de todo. ¡Ojo! Necesita un margin-top en el contenido de abajo.
bg-secondaryColor de fondo secundario (azul oscuro). Las clases bg-* son colores contextuales.
container-fluidOcupa todo el ancho disponible (a diferencia de container que tiene máximo).
navbar-brandEstiliza el logo/nombre de la marca.
text-primaryColor de texto primario (verde claro). Las clases text-* cambian el color del texto.
fs-2 / fw-bold / lh-1fs-2 = tamaño de fuente, fw-bold = negrita, lh-1 = interlineado mínimo.
navbar-togglerEl botón ☰ (hamburguesa) que aparece en móvil.
navbar-toggler-iconEl icono ☰ en sí (tres rayitas).
⚠️ Cuidado con fixed-top: La barra se superpone al contenido. Por eso en el index.html hay un mt en el primer contenedor. ¡Si no le pones margen, el contenido queda detrás!

Menú Offcanvas (panel lateral)

MÓVIL

Al pulsar ☰ en móvil, se abre un panel lateral desde la derecha. Eso es el Offcanvas de Bootstrap.

index.html líneas 22–44
 class="offcanvas offcanvas-end" tabindex="-1" id="navbarOffcanvasLg">
   class="offcanvas-header">
     class="offcanvas-title">...
     class="btn-close btn-close-white" data-bs-dismiss="offcanvas">
class="offcanvas-body"> class="navbar-nav"> class="nav-item">...

🔎 Clase por clase

offcanvasActiva el componente. Por defecto está oculto.
offcanvas-endEl panel se desliza desde la derecha. Existe offcanvas-start, offcanvas-top, etc.
offcanvas-headerCabecera del panel con título y botón cerrar (×).
btn-closeBotón × para cerrar. btn-close-white lo vuelve blanco.
data-bs-dismiss="offcanvas"Atributo que le dice a Bootstrap: «al hacer clic, cierra el offcanvas».
offcanvas-bodyContenido del panel (los enlaces del menú).
navbar-nav / nav-item / nav-linkEstilizan la lista de navegación. active marca el enlace actual, disabled lo deshabilita.
🐛 Error conocido: Bootstrap tiene un bug donde el offcanvas no se cierra al hacer clic en un enlace. Por eso usamos bootstrap.fixed.js — una versión parcheada.

Botones

BTN

Los botones de Bootstrap se crean con btn + un color contextual. Veamos los del proyecto:

index.html líneas 57, 80, 101

 type="button" class="btn btn-primary btn-lg px-4 me-md-2">Principal


 type="button" class="btn btn-outline-secondary btn-lg px-4">Por defecto


 type="submit" class="btn btn-primary bg-success shadow">Submit


 type="button" class="btn btn-primary bg-success shadow" data-bs-toggle="collapse">Leer más...

🔎 Clase por clase

btnClase base para todos los botones. Sin esto no hay estilo de botón.
btn-primaryColor primario (verde claro). Fondo verde claro con texto oscuro.
btn-outline-secondarySolo borde, sin relleno. Al hover se rellena del color secundario.
btn-lgVersión grande. También existe btn-sm.
me-md-2Margin-right en pantallas md+. Separa los botones entre sí.
🎨 ¿Dos colores en un botón? btn btn-primary bg-success: btn-primary da el estilo base, pero bg-success sobrescribe el color de fondo a verde.

Formularios

FORM

Bootstrap estiliza los formularios con clases para inputs, labels, checks, etc.

index.html líneas 66–82
 class="container-sm pt-5 pb-5">
   class="mb-3">
     class="form-label">Email address
     type="email" class="form-control">
     class="form-text">We'll never share...
class="mb-3 form-check"> class="form-check-input" type="checkbox"> class="form-check-label">Check me out

🔎 Clase por clase

container-smAncho máximo pequeño para que el form no se estire.
mb-3Separa cada grupo de formulario (margin-bottom 1rem).
form-labelEstiliza la etiqueta del campo con padding y color.
form-controlClase principal para inputs, selects y textareas. Ancho completo.
form-textTexto de ayuda debajo del input (más pequeño, gris).
form-check / form-check-input / form-check-labelPara checkboxes y radios. Estiliza todo el grupo.

Componente Collapse

COLLAPSE

El collapse permite mostrar/ocultar contenido con un botón. Lo usamos para «Leer más...» del himno.

index.html líneas 91–103

 class="collapse" id="articleMore">
  >Este artículo continúa...
class="btn btn-primary bg-success shadow" data-bs-toggle="collapse" data-bs-target="#articleMore"> Leer más...

🔎 Clase por clase

collapseOculta el contenido. Bootstrap añade transición suave.
data-bs-toggle="collapse"Activa el comportamiento de collapse en el botón.
data-bs-target="#articleMore"Apunta al id del elemento a mostrar/ocultar.
aria-expandedAtributo de accesibilidad. Bootstrap lo actualiza automáticamente.
🔄 Cómo funciona: Bootstrap escucha el clic, encuentra el elemento por su id, y alterna la clase .show. Todo sin escribir JavaScript.
🔗 Relación con offcanvas: Usa el mismo sistema: data-bs-toggle + data-bs-target. Así funcionan collapse, offcanvas, modal y tabs.

Personalización con Sass (SCSS)

AVANZADO

Bootstrap se puede personalizar redefiniendo variables Sass antes de compilar. Así generamos nuestro custom-bootstrap.css desde scss/styles.scss.

scss/styles.scss (resumen)
// 1. Colores de marca
$amargia-yellow:      #FAAC00;
$amargia-green:       #00C83C;
$amargia-light-green: #70FF9B;
$amargia-blue:        #003D43;
$amargia-white:       #F2F2F2;

// 2. Mapeamos a variables de Bootstrap
$primary:   $amargia-light-green;
$secondary: $amargia-blue;
$success:   $amargia-green;
$warning:   $amargia-yellow;

// 3. Botones personalizados
$btn-border-radius: 30px;
$btn-padding-y:    1.25rem;
$btn-padding-x:    2.1875rem;

// 4. Inputs personalizados
$input-border-radius: 15px;
$input-border-color:  $amargia-blue;

// 5. Solo importamos lo necesario
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/navbar";
// ... etc

🔎 Conceptos clave

Variables $En Sass empiezan con $. Bootstrap tiene cientos de variables que puedes sobrescribir.
$primary, $secondary...Variables de color de Bootstrap. Cambiando $primary cambian todos los botones, enlaces y acentos.
@importImportamos solo los componentes que usamos. El CSS final es más ligero.

Consejos finales y buenas prácticas

TIPS
📖 1. La documentación oficial
Bootstrap tiene documentación completa en getbootstrap.com (en español). Cada componente tiene ejemplos listos para copiar.
🧩 2. Piensa en «clases, no CSS»
¿Centrar? → text-center. ¿Margen? → mt-3. ¿Color? → bg-primary. Más rápido y consistente.
📱 3. Mobile first
Las clases sin prefijo (col-10) aplican a móviles. Luego añadimos prefijos: col-sm-8, col-lg-6. Siempre piensa primero en pantalla pequeña.
🔍 4. Inspecciona con F12
Usa las herramientas de desarrollador para ver qué CSS aplica cada clase. Es la mejor forma de aprender.
⚠️ 5. Orden de las clases
El orden no importa. class="btn btn-primary mt-3 shadow" o class="shadow btn mt-3 btn-primary" → funciona igual.
🎯 6. No mezcles Bootstrap con CSS propio sin necesidad
Antes de escribir CSS, pregúntate: «¿Hay una clase de Bootstrap para esto?». Tu CSS solo para cosas muy específicas.
🚀 Resumen: Aprende grid (container → row → col), colores (bg-*, text-*), espaciado (m-*, p-*) y componentes (navbar, btn, form-control, collapse). Con eso ya maquetas páginas enteras.
